# LX 音源质量测试工具

批量测试 LX Music 音源文件对各音乐平台的可用性和音质支持。

## 功能特性

- 🔍 **自动搜索歌曲 ID**：一键从 5 个平台（酷我 / 酷狗 / QQ / 网易 / 咪咕）搜索并匹配歌曲 ID
- 🎵 **逐音质测试**：遍历音源声明的每个音质（master / atmos / hires / flac / 320k / 128k 等）
- 🎯 **实际音质检测**：下载音频文件头，识别真实音质，自动标记"降级"（如请求 master 实际返回 flac）
- 📊 **可视化报告**：按音源 → 平台 → 音质三级展示结果
- 💾 **导出 JSON**：完整测试结果可导出保存

## 下载

从 [Releases](../../releases) 下载最新版 `LX音源测试-x.x.x.exe`，双击运行。

**支持平台**：Windows 10 / 11（64位）

## 使用步骤

### 1. 选择音源目录

点击「选择目录」，选择存放音源 `.js` 文件的文件夹。

支持批量测试多个音源文件，应用会依次加载并测试每个音源。

### 2. 填写歌曲信息

- **歌曲名**（必填）
- **歌手**（推荐填写，能提高 ID 匹配准确率）
- **专辑**（可选）

### 3. 自动搜索各平台 ID

点击「🔍 自动搜索各平台 ID」，应用会：

- 同时从 **酷我 / 酷狗 / QQ / 网易 / 咪咕** 搜索
- 每个平台挑选最匹配的一条
- 自动填充到下方 ID 输入框

**如果某个平台搜不到或匹配错误**，可以手动修改对应输入框的 ID。

### 4. 开始测试

点击「开始测试」，应用会：

1. 依次加载 `api_sources/` 下的每个音源 `.js` 文件
2. 对每个音源，遍历其声明的所有平台
3. 对每个平台，遍历其声明的所有音质
4. 调用音源的 `musicUrl` 接口获取播放链接
5. **下载音频文件头，检测实际音质**
6. 记录结果（URL 是否获取到、是否可访问、实际音质、是否降级）

### 5. 查看结果

结果按「音源 → 平台 → 音质」三级展示：

| 列 | 说明 |
|----|------|
| **请求音质** | 测试时请求的音质等级 |
| **声明** | 音源是否声明支持该音质 |
| **获取URL** | 是否成功从音源拿到 URL |
| **可访问** | URL 是否可正常访问（HTTP 200/206） |
| **实际音质** | 从音频文件头识别的真实音质 |
| **耗时** | 单次请求耗时（毫秒） |
| **URL / 错误** | 成功时的 URL，或失败原因 |

**颜色说明**：

- 🟢 绿色：通过
- 🟠 橙色：**降级**（请求高音质，实际返回低音质）
- 🔴 红色：失败

**降级示例**：

| 请求音质 | 实际音质 | 结果 |
|---------|---------|------|
| master | flac | ⚠️ 降级 |
| atmos | flac | ⚠️ 降级 |
| flac | flac | ✅ 通过 |
| 320k | 320k | ✅ 通过 |

### 6. 导出报告

点击「💾 导出报告」，将完整测试结果保存为 JSON 文件，包含：

- 歌曲信息（名称、歌手、各平台 ID）
- 每个音源的测试结果
- 汇总统计（音源数、平台数、音质数、降级数）

## 实际音质检测原理

应用通过 **下载音频文件的前 16KB**，解析文件头判断真实格式：

| 格式 | 识别方式 | 音质判定 |
|------|---------|---------|
| **FLAC** | 文件头 `fLaC` | 解析 STREAMINFO：采样率 ≥192kHz → master；≥96kHz 或 24bit → hires；否则 flac |
| **MP3** | 文件头 `ID3` 或帧同步 `0xFFFB` | 解析帧头比特率：320kbps → 320k；192kbps → 192k；否则 128k |
| **AAC / M4A** | 文件头 `ftyp` | 按 128k 处理 |
| **OGG** | 文件头 `OggS` | 按 flac 处理 |
| **WAV** | 文件头 `RIFF` | 按 flac 处理 |

**注意**：atmos（杜比全景声）是特殊编码，暂按普通格式识别，可能不准确。

## 自动搜索 ID 的接口来源

应用使用各平台的公开搜索接口，与 **LX Music 内置 SDK** 保持一致的调用方式：

| 平台 | 接口 | 签名 |
|------|------|------|
| 酷我 | `search.kuwo.cn/r.s` | 无 |
| 酷狗 | `songsearch.kugou.com/song_search_v2` | 无 |
| QQ | `u.y.qq.com/cgi-bin/musics.fcg` | zzcSign（SHA1 + 异或 + Base64） |
| 网易 | `music.163.com/api/search/get/web` | 无（公开接口） |
| 咪咕 | `jadeite.migu.cn/music_search/v3/search/searchAll` | MD5 签名 |

如果某平台搜索接口失效，可以手动填写该平台的 ID。

## 沙箱环境说明

音源脚本在 Node.js 的 `vm` 沙箱中执行，模拟以下 API：

| API | 说明 |
|-----|------|
| `globalThis.lx.EVENT_NAMES` | `request` / `inited` / `updateAlert` |
| `globalThis.lx.request(url, options, callback)` | HTTP 请求，回调 `(err, resp, body)` |
| `globalThis.lx.on(event, handler)` | 注册事件处理器 |
| `globalThis.lx.send(event, data)` | 发送事件 |
| `globalThis.lx.utils.crypto.md5(str)` | MD5 工具 |
| `globalThis.lx.utils.buffer.from(buf, enc)` | Buffer 工具 |
| `globalThis.lx.currentScriptInfo` | 脚本元信息（name / version / author / ...） |
| `globalThis.lx.env` | 运行环境，固定为 `'mobile'` |

**沙箱行为对齐 LX Music 官方 `user-api-preload.js`**，确保音源脚本能正常初始化。

## 注意事项

### 音源文件

- 音源 `.js` 文件**不会**被提交到本仓库
- 运行时由用户在应用内选择目录加载
- 建议使用你信任的来源的音源文件

### 请求频率

- 应用默认音质间延迟 200ms
- 如果平台触发风控（返回 `tooManyRequests`），可调大延迟
- 建议不要短时间内重复测试同一首歌

### 网络环境

- 部分接口可能需要科学上网（如咪咕、QQ 某些 CDN）
- 所有请求从**本地**发出，不经过任何第三方服务器

### 音质检测精度

- **FLAC / MP3** 识别准确率高
- **atmos / atmos_plus** 是杜比全景声特殊编码，暂按普通格式处理
- 如果文件头无法识别（罕见），显示为「未知」
