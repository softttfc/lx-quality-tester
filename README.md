# LX 音源质量测试工具

批量测试 LX Music 音源文件对各音乐平台的可用性和音质支持。

## 下载

从 [Releases](../../releases) 下载最新版 `LX音源测试-x.x.x.exe`，双击运行。

## 使用

1. 点击"选择目录"，选择存放音源 `.js` 文件的文件夹
2. 填入测试歌曲名称和歌手
3. 如果能找到各平台的 songId，填到展开的输入框（推荐）
4. 点击"开始测试"
5. 查看结果：每个音源 → 每个平台 → 每个音质的 URL 获取和可访问性

## 原理

- 在本地沙箱中执行音源 JavaScript 脚本
- 模拟 `globalThis.lx` API（`request`、`on`、`send`、`EVENT_NAMES` 等）
- 逐个调用音源的 `musicUrl` 接口
- 验证返回的 URL 是否可访问

## 声明

本工具仅用于音源开发调试，所有请求从本地发出，不涉及任何服务器。
